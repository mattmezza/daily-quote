# daily-quote

A beautiful single-page app that serves inspirational quotes — a daily dose of wisdom, motivation, and reflection.

## About

daily-quote is a minimalist SPA that displays one curated quote at a time. Clean typography, thoughtful spacing, and a serene colour palette make each quote feel like a moment of calm.

## Development

```bash
# Serve locally (static files)
python3 -m http.server 8000
```
